# Bruno Radiadores — sitio listo para Vercel

## Subida a Vercel
Este proyecto es estático (HTML + CSS + JavaScript), por lo que no necesita build.

1. Entrá a Vercel.
2. Elegí **Add New → Project**.
3. Subí/importá este proyecto.
4. Si Vercel pregunta por Framework Preset, podés dejarlo como **Other**.
5. No hace falta configurar Build Command ni Output Directory.
6. Deploy.

También podés subir el contenido de esta carpeta a un repositorio de GitHub y conectarlo con Vercel.
